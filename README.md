# Multi Activity Android App

## Overview
This is a Multi-Page Android Application developed using Kotlin and XML in Android Studio.

The app contains multiple functionalities integrated into separate activities, helping users perform different mathematical operations within a single application.

---

## Features

### 1. Even/Odd Checker
- Takes a number as input
- Checks whether the number is Even or Odd
- Displays the result instantly

### 2. Factorial Calculator
- Calculates factorial of a given number
- Uses recursive logic in Kotlin

### 3. Basic Calculator
Supports:
- Addition
- Subtraction
- Multiplication
- Division
- Decimal operations
- Clear functionality

## Project Structure

- `MainActivity` → Even/Odd Checker
- `Factorial Activity` → Factorial Calculation
- `Calculator Activity` → Basic Calculator

Each activity is connected through navigation buttons using Intents.
